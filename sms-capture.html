iPhone Shortcuts — complete setup

Build a personal automation for transaction SMS only. Menu names can differ slightly by iOS version.

  1. Shortcuts → Automation → New Personal Automation → Message.
  2. Choose bank sender(s) or sender filter. Add transaction keywords such as “debited”, “credited”, “UPI”, “spent”, “received”. Do not include OTP, login, balance-only, or promotional SMS.
  3. Set the automation to run immediately / disable confirmation if the option is available and you are comfortable with automatic forwarding.
  4. Add action to select the automation’s incoming Message variable (full SMS text). Use this variable, not a manually typed sample.
  5. Add Get Contents of URL. URL: https://magxbczgrxeypryjborr.supabase.co/functions/v1/sms-capture/capture; Method: POST.
  6. Headers: Authorization = Bearer YOUR_GENERATED_TOKEN; Content-Type = application/json.
  7. Request Body → JSON. Add message mapped to the incoming Message variable. Add sender mapped to Sender/From if iOS exposes it; otherwise omit/leave empty. Identifier extracted from the SMS is used first.
  8. Save and test with a transaction alert. Confirm it lands in Cash Book or SMS Review Inbox. Re-forward the same SMS to verify duplicate handling. Check Cash Book before using with live messages.

Token security: Never share or screenshot your token. Exposed tokens should be revoked and replaced. Do not forward OTP/authentication SMS.
