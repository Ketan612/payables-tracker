Set up iPhone SMS capture

One-time setup for a new iPhone. Your existing automatic SMS capture keeps working; the daily particulars review is a separate shortcut.

  1. Generate your private tokenTap Generate new token below, then copy it. Never share it or include it in a screenshot.
  2. Run Save File onceOpen the supplied Save File Shortcut, enter your token when prompted, and let it create the Payables Tracker folder and save the token. No manual folder creation is needed.
  3. Set up Capture Financial MessagesOpen the supplied capture Shortcut, keep the Bearer Authorization header and capture request configured, then create a Personal Automation → Message on your iPhone to run it automatically.
  4. Map your bank accountAdd the account identifier shown in your bank SMS to the Cash Book account below.
  5. Test one transaction SMSSend a genuine low-value transaction alert through the automation, then confirm it appears in the SMS inbox or Cash Book.
